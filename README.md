# Marcelo da Paixão Portfolio

Static portfolio for GitHub Pages, focused on FlowPilot AI as the main case and selected GitHub projects as supporting work.

## Structure

- `index.html` - bilingual portfolio content.
- `styles.css` - responsive visual design.
- `script.js` - English/Portuguese language switch.
- `assets/flowpilot/` - FlowPilot AI screenshots and demo GIF.

The default language is English. Portuguese can be opened with `?lang=pt` or through the page toggle.
